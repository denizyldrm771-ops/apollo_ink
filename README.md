# Apollo Ink V36 — From Reference

This is a clean, standalone rebuild of the Ink Artist Studio Assistant UI. It does not depend on the previous V31/V32/V33/V34 application structure.

## Main screens
- Ana Sayfa
- Randevular / visual time-line
- Müşteri Profili
- Tasarım Çalışmaları
- Finans & Analiz
- Stok Yönetimi (adet + dynamic status bar)
- Asistan
- IBAN / Ödeme Bilgileri
- Ayarlar
- Hamburger side menu

- Apollo red: #F90004
- Charcoal: #2E2F33
